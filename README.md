# Element Clash

고전 온라인 액션 RPG의 팀 전투 감각을 현대 브라우저에서 재해석한 독립 전투 프로토타입입니다. 원작 캐릭터·그래픽·음원은 포함하지 않습니다.

## 실행

이 폴더에서 아래 명령을 실행한 뒤 `http://127.0.0.1:4180`을 엽니다.

```powershell
node server.mjs
```

같은 와이파이의 다른 기기는 이 컴퓨터의 IPv4 주소에 `:4180`을 붙여 접속할 수 있습니다. 인터넷 친구와 대전하려면 아래의 공개 배포 과정이 필요합니다.

## 조작

- 이동·방향: WASD 또는 방향키
- 근접 공격: J
- 원거리 공격: K
- 정령 마법: L
- 방어·카운터: Space
- 질주: Shift
- 일시정지: Esc

모바일에서는 화면의 조이스틱과 전투 버튼을 사용합니다.

시작 화면에서 네 모드를 고를 수 있습니다.

- **1대1 연습전**: 내 직업과 컴퓨터 직업을 각각 선택하는 완화된 AI 5 K.O. 선취전입니다.
- **4대4 팀전**: 아군 AI 3명과 함께 싸우는 12 K.O. 선취전입니다.
- **랜덤 대전**: 같은 서버에서 기다리는 다른 접속자와 자동으로 연결되는 1대1입니다.
- **초대 대전**: 방을 만든 사람에게 표시된 6자리 코드를 상대가 입력하는 1대1입니다.

온라인 대전은 방을 먼저 만든 쪽의 전투 판정을 기준으로 두 화면을 실시간 동기화합니다.

초보자 밸런스에서는 캐릭터 표시 크기보다 피격 판정을 넓게 잡고, 근접 공격의 사거리·피해를 강화했습니다. 근접 피격은 넉백이 매우 작아 밀려나기 전에 연속 공격이 가능하며, 원거리는 MP 소비·쿨타임·사거리·피해가 제한됩니다. 1대1 연습 AI는 체력 76%, 공격력 54%, 느린 판단 주기로 설정되며 플레이어 공격에는 18% 보정이 붙습니다.

## 전투 감각

- 모든 캐릭터와 AI는 8방향으로 이동·조준합니다.
- 달리다 키를 놓으면 관성으로 미끄러지고, 반대 방향 입력으로 제동할 수 있습니다.
- 속도가 붙은 상태로 벽이나 장애물에 닿으면 반동하며 흙먼지가 발생합니다.
- 근접 공격은 직업별 무기 모션을 가지며 정면의 적 투사체를 쳐낼 수 있습니다.
- 원거리 공격은 MP와 유효거리가 있어 무제한 저격할 수 없습니다.
- 방어는 정면 140도를 막고 BP를 소비합니다. 방어 중 공격 입력은 가능하지만 공격 동작 동안 방패가 열립니다.
- 마법은 바라보는 방향의 룬에 예고 후 발동하는 직업별 범위 공격입니다.

## 캐릭터 아트

인게임 캐릭터는 도형 조립 그림이 아니라 `dist/assets/`의 투명 PNG 8방향 애니 SD 스프라이트를 사용합니다. 검사·궁수·마법사 모두 검·활·지팡이가 캐릭터 일러스트 자체에 포함되어 있으며, 방향별 프레임은 4열×2행 순서로 재생됩니다.

## GitHub 업로드와 공개 대전

1. GitHub에서 `New repository`를 누르고 `element-clash`라는 공개 저장소를 **빈 상태**로 만듭니다.
2. 생성 직후 안내 화면의 `uploading an existing file`을 누릅니다.
3. 탐색기에서 `survival-arena` 폴더 자체가 아니라 그 **안의 내용 전체**(`dist`, `server.mjs`, `package.json`, `render.yaml`, `README.md`)를 선택해 끌어다 놓습니다.
4. 아래 `Commit changes`를 누릅니다.

GitHub Pages는 정적 파일만 제공하므로 랜덤·초대 매칭 서버를 실행할 수 없습니다. 온라인 대전까지 공개하려면 Render에서 `New +` → `Blueprint` → 이 GitHub 저장소 선택 → `Apply`를 누릅니다. 포함된 `render.yaml`이 실행 방법을 자동 설정합니다. 배포가 끝나면 Render가 제공한 `https://...onrender.com` 주소 하나를 두 사람이 같이 사용합니다.
